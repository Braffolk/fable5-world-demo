# Final Integrated Spec Audit Closure

**Date:** 2026-07-13
**Scope:** final independent science/beauty, repository/cook, and standalone-evidence audits of `docs/tasks/2026-07-13/SPEC-MICROTOPOGRAPHY.md`
**Status:** all reported critical/high findings are closed in the rewritten spec; no implementation is authorized before user approval

## 1. Scientific And Beauty Closure

- The first Moore protocol was rejected, not patched into a false win. A true
  target-derived 0.25 m parent is an oracle unavailable in production, its
  packed-null delta is not the overlapping-filter `B2` band, and Moore lacks
  transferable per-band error plus replicated comparable condition strata.
- Moore is now `target_evidence_insufficient` for owner selection. Optional M0/M1
  work is an ideal synthetic engineering screen only, with exact packed
  observation constraints, separate `F4` analysis, grid-phase sensitivity, and a
  plot-scale render protocol. It cannot select or activate an owner.
- Source repair no longer treats local DTM roughness as sensor noise. Uncertainty
  and interpolation scales require source/support/overlap/control evidence,
  contiguous shape-matched pseudo-voids, and protected counterexamples; unsupported
  repair classes abstain.
- ETAK shoreline geometry is a dated positional corridor, not a surveyed toe.
  DTM-in-water values require source semantics; otherwise official/surveyed levels
  or abstention apply. Continuous shoreline, bed membership, watercover, and the
  renderer-visible intersection have explicit compatibility gates.
- Production morphology requires qualified Estonia target data and a separately
  reviewed acquisition protocol plus target-specific scientific preregistration.
  The missing corpus is not hidden by a generic procedural or learned prior.

## 2. Repository And Delivery Closure

- The no-runtime-synthesis law remains absolute, but the spec now truthfully
  authorizes one minimal representation-sampling fix: trees/boulders and
  understory/debris must follow the same packed fine/morph surface as terrain and
  grass. No wire, shader, provenance, or synthesis path is added.
- Release is a defined two-artifact transaction:
  `corrected-structural-base-v1`, then bound
  `evidence-microtopography-v1`, merged verification, manifest-bound boot, and one
  atomic `latest.json` update only after user acceptance.
- The Stage 1 authority, reducer-support, transient, apron, promotion, and ancestor
  sets are distinct. Corrected LOD0 authority derives from the canonical fine
  structural master; peak work is not misreported as the old 17-file diagnostic.
- The legacy post-height mutating waterbed pass is forbidden for recipe builds.
  Bed enters structural authority before hierarchy; later water layers are
  read-only and `WATERBED_FLAG` prevents double carving.
- The real-WebGPU gate names the exact URL, command, viewport, settle count,
  preview manifest selection, expected manifest SHA, and evidence schema. A URL is
  never handed to the user before that exact gate passes.

## 3. Evidence And Coverage Closure

- The regime contract is materialized as a strict schema, 26 complete initial
  rows, and a one-to-one status manifest. It contains no Estonia owner, positive
  band claim, release extent, or approval.
- Every structural, pilot, or national claim binds an expected-domain manifest
  generated before release enumeration. Missing expected chunks become `U` and
  unexpected chunks become `A`; a cook cannot cherry-pick easy territory and call
  coverage complete.
- Repository snapshots with unverified officialness or code-read status are
  labeled as such. Consequential reuse requires linked official-code review,
  license closure, and target evidence rather than a downloaded tarball.
- Orthophoto acquisition names the exact Stage 1 RGB/CIR archives and retains ETAK
  as the accepted geometry unless a separately scored, tightly registered,
  temporally compatible optical challenger passes.

## 4. Holistic Outcome

The fixes preserve one coherent architecture: deterministic evidence-based source
repair; a strict typed regime/abstention graph; target-supported per-regime
specialist competition with a valid no-owner outcome; one deterministic absolute
finest master; and existing packed-height delivery. Exact synthetic observation
constraints are never transferred to fallible Maa-amet DTM, the minimal runtime
sampling repair never becomes synthesis, and storage/release rigor never substitutes
for visible realistic morphology.

The next authorized action after user approval is the bounded Stage 1 structural
proof and acquisition-protocol closure. Replacement morphology implementation
remains blocked by qualified Estonia target evidence and a user-reviewed
target-specific preregistration.
