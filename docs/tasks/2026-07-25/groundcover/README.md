# Ground-cover task index — 2026-07-25

This directory is the only current entry point for the grass and moss work.

- [`active/`](active/) contains the approved product design, the current visual-issue ledger,
  and the mathematics used by the live Calamagrostis preview.
- [`archive-inactive/`](archive-inactive/) contains rejected, failed, superseded, unapproved,
  or merely parked investigations. **Nothing in that tree authorizes implementation.**

The renderer research is stopped at the user's request. Current work is botanical source
modelling only. The live application still has two compatibility paths:

1. the deprecated but still-default multi-species periodic renderer; and
2. the isolated `grassprofile=2` Calamagrostis preview.

Neither path is an accepted generic multi-species ground-cover solution.
