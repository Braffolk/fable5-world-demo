# Rejected and inactive ground-cover archive

**Everything below this directory is inactive. Do not implement from it.**

The archive preserves proofs, measurements, failed gates, superseded specifications, and
reproduction notes so that rejected work is not accidentally repeated. A document may contain
useful mathematics without making its proposed runtime representation active.

Status groups:

- [`REJECTED-RESULTS.md`](REJECTED-RESULTS.md) — measured or analytic RED/NO-GO families.
- [`PARKED-OR-SUPERSEDED.md`](PARKED-OR-SUPERSEDED.md) — incomplete, unrun, or replaced plans.
- [`RETAINED-MATH-REFERENCES.md`](RETAINED-MATH-REFERENCES.md) — useful theorems retained only
  as references; their associated implementations remain inactive.
- [`by-original-date/`](by-original-date/) — immutable historical records grouped by their
  original date so relative chronology remains legible.

No file in this archive is a current spec, task, handoff, or implementation authority.
